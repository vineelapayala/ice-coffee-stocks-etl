# Clone and Run — ICE Certified Coffee Stocks ETL

## 1. Prerequisites

### Install Git

Open PowerShell or the VS Code terminal and run:

```powershell
winget install --id Git.Git -e --source winget
```

Verify:

```powershell
git --version
```

### Check Python

### Install Python 3.13

This project is tested with Python 3.13.1

If Python 3.13 is not installed, you can install it using:

```powershell
winget install Python.Python.3.13

```powershell
python --version
```

If Python is not installed, install it from the official Python website.

---

# 2. Clone the Repository

```powershell
git clone https://github.com/vineelapayala/ice-coffee-stocks-etl.git
cd ice-coffee-stocks-etl
```

---

# 3. Create and Activate Virtual Environment

```powershell
py -3.13 -m venv .venv
```

Activate it:

```powershell
.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, run:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

Then activate again:

```powershell
.venv\Scripts\Activate.ps1
```

You should see:

```text
(.venv)
```

at the beginning of the terminal prompt.

---

# 4. Install Dependencies

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

---

# 5. Verify the Installation

Run:

```powershell
python -c "import pandas, requests, xlrd, nodriver, pymongo, dotenv; print('All dependencies installed successfully')"
```

---

# 6. Run the Arabica Extraction

Arabica data is obtained from ICE Report 42.

Run:

```powershell
python -m src.run_arabica
```

The downloaded files will be stored under:

```text
data/raw/arabica/
```

---

# 7. Start Microsoft Edge for Robusta Discovery

Robusta historical report URLs are dynamically generated by ICE Report 173.

Open a new VS Code terminal and run:

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" `
  --remote-debugging-port=9223 `
  --user-data-dir="$env:TEMP\ice-edge-profile" `
  "https://www.ice.com/report/173"
```

Keep this Edge window open.

If the Edge executable is installed in another location, locate `msedge.exe` and update the path accordingly.

---

# 8. Verify the Edge Debugging Port

In another VS Code terminal:

```powershell
Test-NetConnection localhost -Port 9223
```

Look for:

```text
TcpTestSucceeded : True
```

---

# 9. Run Robusta Report Discovery

Keep Edge running.

In another VS Code terminal, activate the virtual environment if necessary:

```powershell
.venv\Scripts\Activate.ps1
```

Then run:

```powershell
python -m src.robusta_discovery
```

The script will:

1. Connect to the existing Edge browser.
2. Open ICE Report 173.
3. Select Stock Figures.
4. Set the historical start date.
5. Set the end date.
6. Click SUBMIT.
7. Intercept the ICE API response.
8. Extract the dynamically generated Robusta CSV URLs.
9. Save the API response.
10. Save the discovered report URLs.

The generated files will be stored under:

```text
data/raw/robusta_discovery/
```

### CAPTCHA

If ICE displays a CAPTCHA, complete it manually in Edge.

The script will then continue listening for the report API response.

---

# 10. Download the Robusta Reports

After discovery completes, run:

```powershell
python -m src.run_robusta
```

The downloaded files will be stored under:

```text
data/raw/robusta/
```

---

# 11. Run the Complete ETL Pipeline

Once both Arabica and Robusta raw data have been downloaded, run:

```powershell
python main.py
```

The pipeline will:

```text
Arabica Raw XLS
      │
      ▼
Arabica Parser
      │
      │
      ├──────────────┐
      │              │
      ▼              ▼
Robusta Raw CSV   Validation
      │              │
      ▼              ▼
Robusta Parser   Quality Report
      │              │
      └──────┬───────┘
             ▼
     Consolidated Dataset
             │
        ┌────┴────┐
        ▼         ▼
       CSV     MongoDB
```

The consolidated dataset will be generated as:

```text
coffee_stock_consolidated.csv
```

The data quality report will be generated under:

```text
data/quality/data_quality_report.json
```

# 14. MongoDB Atlas Configuration — Optional

MongoDB loading is optional.

Create a `.env` file in the project root:

```text
MONGODB_URI=your_mongodb_connection_string
MONGODB_DATABASE=your_database_name
MONGODB_COLLECTION=your_collection_name
```

Do not commit `.env` to Git.

The `.gitignore` already excludes:

```text
.env
```

Then run:

```powershell
python main.py
```

The validated records can be loaded into MongoDB Atlas.

# 16. Quick Start

If Git and Python are already installed, the basic workflow is:

```powershell
git clone https://github.com/vineelapayala/ice-coffee-stocks-etl.git
cd ice-coffee-stocks-etl

python -m venv .venv
.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
pip install -r requirements.txt

python -m src.run_arabica
```

Then start Edge:

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" `
  --remote-debugging-port=9223 `
  --user-data-dir="$env:TEMP\ice-edge-profile" `
  "https://www.ice.com/report/173"
```

Then, in another VS Code terminal:

```powershell
.venv\Scripts\Activate.ps1
python -m src.robusta_discovery
```

After discovery:

```powershell
python -m src.run_robusta
```

Finally:

```powershell
python main.py
python -m pytest -v
```

# 17. Re-running the Project

The extraction scripts are designed to avoid unnecessarily downloading files that already exist locally.

For example:

```text
Already exists: coffee_cert_stock_20261001.xls
```

or:

```text
Already exists: Stock_Report_RC_20261002_103030.csv
```

This allows the pipeline to be rerun without downloading every source file again.

# 18. Troubleshooting

### Git command not recognized

Restart VS Code after installing Git:

```powershell
git --version
```

---

### Python command not recognized

Verify:

```powershell
python --version
```

If unavailable, install Python and reopen VS Code.

---

### Virtual environment activation fails

Run:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

Then:

```powershell
.venv\Scripts\Activate.ps1
```

---

### Edge debugging port is unavailable

Check:

```powershell
Test-NetConnection localhost -Port 9223
```

If it returns:

```text
TcpTestSucceeded : False
```

close the Edge instance started for this project and start it again with:

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" `
  --remote-debugging-port=9223 `
  --user-data-dir="$env:TEMP\ice-edge-profile" `
  "https://www.ice.com/report/173"
```

---

### `ModuleNotFoundError`

Make sure the virtual environment is active:

```powershell
.venv\Scripts\Activate.ps1
```

Then:

```powershell
pip install -r requirements.txt
```

---

### Robusta discovery cannot find the API response

Make sure:

1. Edge is running with port `9223`.
2. `Test-NetConnection localhost -Port 9223` returns `True`.
3. The ICE Report 173 page is open.
4. CAPTCHA has been completed if displayed.
5. The report has been submitted.

Then rerun:

```powershell
python -m src.robusta_discovery
```

This is the complete clone → install → extract → discover → download → ETL → validate → test workflow.
